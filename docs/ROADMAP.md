# Roadmap (boundaries, not a backlog to implement)

**Listing a feature here is not permission to build it.**

## Now — Combat 0.1.x

**ELARIS Combat Prototype 0.1.5** is the frozen rules milestone.

Priority:

1. Full human playtests
2. Fun / pace / readability
3. Basic balance of the two 40-card lists (report before changing numbers)
4. Blocking bugs only as they appear

Do **not** enter Combat 0.2 without explicit user approval.

## Later — only after 0.1.x is stable and approved

- **Combat 0.2** (scope TBD by user; not started)

## Explicitly out of scope for 0.1.x

Login, shop, map, database, new decks as a “content drop”, large balance passes, animation/SFX packages, engine rewrites beyond what 0.1.5 already did — unless the user asks.
